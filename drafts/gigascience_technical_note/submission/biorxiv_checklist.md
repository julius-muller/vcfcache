# bioRxiv submission checklist

## Manuscript package

- [ ] Review the generated PDF with figures embedded near first citation.
- [ ] Confirm title, abstract, author order, affiliations and corresponding
      author match the submission form.
- [ ] Confirm every author has approved public preprint posting.
- [ ] Select Bioinformatics as the primary subject category.
- [ ] Select the preprint license after checking funder requirements.
- [ ] Upload the supplementary PDF and any allowed supporting tables.
- [ ] Add permanent code and data links to the Data/Code fields.
- [ ] Confirm that no restricted or identifying human data are embedded.
- [ ] Confirm that the manuscript is not already accepted by a journal.

## Final local checks

- [ ] `make release-check` passes.
- [ ] PDF text, mathematical symbols, links and special characters render.
- [ ] Figure labels remain legible at normal page width.
- [ ] All referenced files and persistent identifiers resolve.
- [ ] The submitted PDF and supplementary file hashes are recorded.
