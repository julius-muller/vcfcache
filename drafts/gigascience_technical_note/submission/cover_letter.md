# Draft cover letter to GigaScience

Dear Editors,

We submit **“VCFcache reduces redundant computation in repeated variant
annotation”** for consideration as a Technical Note in *GigaScience*.

Variant annotation pipelines repeatedly compute consequences for alleles that
have already been processed in other samples. VCFcache adds a tool-agnostic
reuse layer: it retrieves annotations generated by an immutable recipe and
sends only cache misses to the original annotator. In 52 held-out whole
genomes, VCFcache produced median end-to-end speedups of up to 9.21-fold with
Ensembl VEP and 2.05-fold with fastVEP. All 312 cached outputs passed
annotator-specific semantic comparison. A controlled real-WGS experiment
further showed that observed runtime follows a simple hit-rate model from fast
to all-day annotation pipelines.

The work fits the journal's emphasis on open, reusable and reproducible
software. VCFcache is GPL-3.0-only software, uses standard VCF/BCF interfaces,
and distributes public caches through Zenodo. The submission will include a
versioned code archive, benchmark source tables, manifests, figure scripts,
test input and expected outputs under persistent identifiers.
