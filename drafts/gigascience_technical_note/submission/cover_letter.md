# Draft cover letter to GigaScience

Dear Editors,

We submit **“VCFcache reduces redundant computation in repeated variant
annotation”** for consideration as a Technical Note in *GigaScience*.

Variant annotation pipelines repeatedly compute consequences for alleles that
have already been processed in other samples. VCFcache adds a tool-agnostic
reuse layer: it retrieves allele-level INFO payloads generated by a fixed recipe and
sends only cache misses to the original annotator. In 52 held-out whole
genomes, VCFcache produced median end-to-end speedups of up to 9.21-fold with
Ensembl VEP and 2.05-fold with fastVEP. In a matched 12-genome GRCh38
comparison using native annotation recipes, median WGS speedups were 9.50-fold
for VEP, 2.54-fold for clinical fastVEP and 10.78-fold for clinical SnpEff.
All 312 external-WGS outputs and all 176 eligible final-campaign outputs passed
annotator-specific semantic comparison. Controlled real-WGS experiments
further showed that cache coverage determines relative benefit while annotation
cost determines the absolute hours returned; measured cohort caches repaid
their build cost after two subsequent genomes. This incremental execution
strategy combines precomputed payload lookup with automatic execution for
misses, so users retain their chosen annotation workflow. Equivalence is
limited to the tested fields and recipes; the manuscript explicitly reports
the VEP HGNC exception and four excluded SnpEff warning-order cells.

The work fits the journal's emphasis on open, reusable and reproducible
software. VCFcache is GPL-3.0-only software, uses standard VCF/BCF interfaces,
and distributes public caches through Zenodo. The submission will include a
versioned code archive, benchmark source tables, manifests, figure scripts,
test input and expected outputs under persistent identifiers.
