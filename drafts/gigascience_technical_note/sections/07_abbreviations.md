# List of abbreviations

**AF:** allele frequency; **BCF:** binary variant call format; **BGZF:** blocked
GNU Zip Format; **CSQ:** consequence annotation field; **GRCh:** Genome
Reference Consortium human assembly; **KPGP:** Korean Personal Genome Project;
**PGP:** Personal Genome Project; **SGDP:** Simons Genome Diversity Project;
**VCF:** variant call format; **VEP:** Ensembl Variant Effect Predictor;
**WGS:** whole-genome sequencing.
