# Excluded pilot

This first assay-extension attempt must not be used for figures or claims.
Short Panel/WES cells were dominated by cold-state condition order before an
independent warm-state control was introduced. Representative VEP/WES pairs
were 181.6 s cached followed by 27.3 s direct, and 261.5 s direct followed by
116.8 s cached. Those values do not estimate cache benefit.

The replacement campaign is
`external-assay-v3-independent-af001-warm`. It uses a separate KPGP-00319
assay subset as one untimed pre-run before either retained condition and still
records only one direct and one cached measurement per evaluation cell.
